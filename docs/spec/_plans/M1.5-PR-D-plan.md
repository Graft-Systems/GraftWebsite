## 1. Goal

After this PR lands:

- A new `services/api/spray/connectors/` namespace exists (per CODEBASE_PLAN.md §300 — connectors are vendor APIs the customer authenticates against; providers are read-only feeds we own the auth on).
- A `connectors/sensors/pessl/` package implements the FieldClimate v2 OAuth 2.0 partner-app flow end to end: authorize → callback → token persist → token refresh → station discovery → 15-min polling → canonical-schema normalization → lake event.
- Three new Django models: `IntegrationConnection` (org-scoped, vendor-agnostic, encrypted token blob), `SensorStation` (vendor's station ID + optional `Block` link + `quality_flag` history), `SensorReading` (canonical sensor schema per §12A.3, hourly grain, unique `(station, ts)`).
- A vendor-agnostic `SensorConnector` Protocol so PR-E (Davis + METER) drops in without API churn — same shape as `WeatherProvider` / `ExternalRiskIndexProvider` from M0-06.
- A `connectors/credentials.py` Fernet-based encryption helper. Key sourced from `SPRAY_INTEGRATION_FERNET_KEY` env var. Plaintext tokens never persisted.
- API endpoints: OAuth start, OAuth callback, station list, link station to block, integration list, disconnect.
- A Celery beat task `pessl_pull` runs every 15 min, fans out per active connection × station, dedups via `(station, ts)` upsert.
- Gap-fill rule wired into `quality_flag`: station offline >4h → reading marked `quality_flag = "gap_filled"`. Banner surfaces in UI; ensemble layer (PR-C) reads the flag and lowers verdict confidence (PR-C already supports `quality_flag` on RiskRecord input).
- Lake event `sensor.reading_pulled` (new schema, additionalProperties: false). Emitted per reading. CI's `check_event_schemas.py` picks it up automatically.
- Frontend: `/spray/integrations` page (currently a placeholder per spec §6.5 mention) gains a "Connect Pessl" button → OAuth round-trip → station-list view → per-station "Link to block" UI.
- ~35 new tests: token-encryption round-trip, OAuth state-CSRF check, polling task happy path, gap-fill path, idempotency on retry, schema-drift handling for Pessl response variants.

This PR does NOT wire:

- Davis WeatherLink polling adapter (PR-E, sibling).
- METER ZENTRA push webhook (PR-E).
- Sencrop OAuth (Phase 2, deferred per spec §12A.2).
- HMAC-SHA256 single-account fallback for Pessl (lower priority; partner-app OAuth is the MVP path per spec §12A.1).
- Sensor-reading → ensemble feature wiring (RiskRecord runners already accept enriched WeatherWindow; sensor-fed enhancement of the window is a follow-up PR-D.5 or rolled into PR-E).

| Q5 | **Org-scoped credential isolation** | Yes — `IntegrationConnection.org_id` is required + tenant-scoped via `OrgScopedManager` (same pattern as Vineyard/Block) | Cross-org credential read is the worst-case breach scenario; RLS + manager both enforce. |
| Q6 | **Backfill on connect** | Pull last 14 days of readings (matches M0-06 weather backfill default) | Pessl free tier may rate-limit; surface as banner if so. |
| Q7 | **What gets emitted to the lake** | One `sensor.reading_pulled` per reading | Matches `weather.observation_pulled` cardinality. High volume but manageable; lake ETL already handles it. |
| Q8 | **Disconnect semantics** | Soft-delete: set `IntegrationConnection.disconnected_at`, keep historical readings (they're already in the lake), stop polling | Reconnect resumes from last `ts` per station. |

## 4. Architecture

### 4.1 Namespace

```
services/api/spray/connectors/
├── __init__.py
├── base.py                    # SensorConnector Protocol + exceptions
├── credentials.py             # Fernet helpers; never logs plaintext
├── registry.py                # vendor → class lookup
└── sensors/
    └── pessl/
        ├── __init__.py
        ├── client.py          # HTTP client; OAuth + station + data endpoints
        ├── oauth.py           # auth-URL builder, code exchange, refresh
        ├── connector.py       # SensorConnector implementation
        └── normalizer.py      # Pessl payload → canonical schema
```

### 4.2 SensorConnector Protocol (mirrors WeatherProvider)

```python
class SensorConnector(Protocol):
    VENDOR_SLUG: str  # "pessl"

    def list_stations(self, connection: IntegrationConnection) -> list[VendorStation]: ...
    def fetch_readings(
        self, connection: IntegrationConnection, station: SensorStation, since: datetime
    ) -> list[SensorReading]: ...
    def health(self, connection: IntegrationConnection) -> ProviderHealth: ...
```

### 4.3 Models

**`IntegrationConnection`** — org-scoped credential record.

- `id: UUID`
- `org: FK → Org`
- `vendor: str` ("pessl" | "davis" | "meter" | "sencrop")
- `vendor_account_id: str` (Pessl's user ID, returned post-OAuth)
- `token_ciphertext: bytes` (Fernet-encrypted JSON `{access_token, refresh_token, expires_at}`)
- `status: str` ("active" | "needs_reauth" | "disconnected")
- `connected_at: datetime`, `disconnected_at: datetime | null`, `last_health_at: datetime | null`
- Manager: `OrgScopedManager(via="org_id")`. RLS policy on `(org_id = current_org_id())`.
- Unique: `(org, vendor, vendor_account_id)`.

**`SensorStation`** — vendor's station, optionally linked to one or more Blocks.

- `id: UUID`
- `connection: FK → IntegrationConnection`
- `vendor_station_id: str` (Pessl's station serial)
- `name: str`, `lat/lon: Decimal`, `last_seen_at: datetime | null`
- `linked_blocks: M2M → Block` (through `SensorStationBlock` for an audit trail of who linked when)
- Unique: `(connection, vendor_station_id)`.

**`SensorReading`** — canonical sensor schema per §12A.3.

- `id: UUID`
- `station: FK → SensorStation`
- `ts: datetime` (UTC, hour-truncated where source is hourly)
- `air_temp_c, rh_pct, leaf_wetness_min, precip_mm, wind_speed_ms: Decimal | null`
- `source: str` (== `connection.vendor`)
- `device_id: str` (== `station.vendor_station_id`)
- `quality_flag: str` ("ok" | "estimated" | "gap_filled" | "stale" | "bad")
- Manager: `OrgScopedManager(via="station__connection__org_id")`.
- Unique: `(station, ts)`. `bulk_create(update_conflicts=True)` on retry.
- No `org_id` denorm; same call as M0-06 `WeatherObservation`.

### 4.4 OAuth flow

1. **Start** — `GET /api/spray/orgs/<org>/integrations/pessl/oauth/start` →
   - Server generates random `state` (signed with org_id + nonce + ts), persists to a short-lived `OAuthState` row (TTL 10 min).
   - Returns `{ authorize_url: "https://api.fieldclimate.com/v2/oauth/authorize?..." }`.
   - Frontend opens in same tab.
2. **Callback** — `GET /api/spray/integrations/pessl/oauth/callback?code=...&state=...` →
   - Server verifies `state`, looks up org_id from the OAuthState row.
   - Exchanges `code` for tokens at Pessl's token endpoint.
   - Encrypts and writes `IntegrationConnection`.
   - Emits `integration.connected` event.
   - Redirects to `/spray/integrations?connected=pessl`.
3. **Refresh** — On 401 from any data call, `oauth.py:refresh()` swaps refresh-token → new access. Re-encrypts. If refresh itself 401s, set `status = "needs_reauth"`, emit `integration.needs_reauth`, frontend banner prompts re-OAuth.

### 4.5 Polling task

`graft_worker/tasks/pessl_pull.py`:

- `pull_all_pessl_stations` (beat, every 15 min) — selects active `IntegrationConnection` where `vendor="pessl"`, fans out one task per `SensorStation` linked to ≥1 Block.
- `pull_pessl_station(connection_id, station_id)` — calls connector.fetch_readings(since=last_ts or 14d-ago), bulk-upserts SensorReading, emits one `sensor.reading_pulled` per reading, updates `station.last_seen_at`.
- Gap-fill: if `last_seen_at` >4h old, the next pull marks new readings `quality_flag = "gap_filled"` until station catches up.

## 5. Implementation steps

1. **Step 1 — Models + migration** (~150 LoC). Three new tables + `OAuthState`. RLS on `IntegrationConnection`. Reversible.
2. **Step 2 — Credentials helper** (~80 LoC). Fernet wrapper, env-var key, encrypt/decrypt JSON token blob, never logs plaintext.
3. **Step 3 — SensorConnector Protocol + base exceptions** (~60 LoC). Mirrors `WeatherProvider`.
4. **Step 4 — Pessl OAuth module** (~200 LoC). Authorize URL builder, code exchange, refresh, error mapping.
5. **Step 5 — Pessl client + normalizer** (~250 LoC). HTTP wrapper with auto-refresh on 401, station list, data fetch, payload → canonical-schema mapper, leaf-wetness already in minutes (no conversion).
6. **Step 6 — Pessl connector class** (~80 LoC). Wraps client + normalizer behind the Protocol.
7. **Step 7 — Celery task** (~100 LoC). Beat + per-station task; gap-fill logic; idempotent upsert.
8. **Step 8 — API views + URLs** (~250 LoC). All six endpoints; serializers; permission classes.
9. **Step 9 — Frontend** (~250 LoC). Integrations page + detail page + components.
10. **Step 10 — Schema registry** (~30 LoC). `sensor.reading_pulled.v1.json` + integration.connected/disconnected/needs_reauth events.
11. **Step 11 — Tests** (~400 LoC). Listed below.
12. **Step 12 — CHANGELOG + docs**.

## 7. Risks

| ID | Risk | Mitigation |
|---|---|---|
| D1 | **Pessl partner-app approval delay.** Pessl reviews partner apps manually. Could block PR for days. | Plan dev against the published v2 API docs + a recorded fixture. Submit partner-app application Day 1 of work. Land code with `responses`-mocked client. Smoke-test live the moment approval lands. |
| D2 | **Token leak via logs.** Stack trace, Sentry, request log could surface plaintext token. | `credentials.py` only ever returns plaintext to the connector module; never to views, never to `__repr__`. All Pessl HTTP calls strip `Authorization` header from any logged request. Sentry scrubber rule on `*token*` field names. |
| D3 | **OAuth state CSRF.** Attacker forges callback with their own code. | State is HMAC-signed (server secret) with org_id + nonce + ts. Verified server-side; expired states (>10 min) rejected. |
| D4 | **Pessl rate limits per tier.** User on Tier 1 → 48 req/station/day → 15-min polling will 429. | Connector reads tier from health probe; degrades cadence to hourly automatically; surfaces banner. Tier-2 user gets full 15-min cadence. |
| D5 | **Schema drift.** Pessl renames a field; readings stop normalizing. | Normalizer has explicit field lookups + warning log on missing fields; CI alert on schema drift via captured fixture diff (Phase 2; for now manual review). |
| D6 | **Cross-org credential read.** Worker pulls Org A's token but writes readings under Org B. | Poll task takes `connection_id` (no Block lookup); RLS + manager prevent cross-org writes. Tested in `test_integration_rls.py`. |
| D7 | **Refresh-token rotation.** Pessl rotates refresh on use; we lose access if write fails. | `refresh()` writes new tokens in a single `transaction.atomic()`; on any DB error the old refresh stays valid (Pessl allows the previous refresh until next use). |
